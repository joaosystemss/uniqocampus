# 🎓 UniQ Campus

> Plataforma web desenvolvida para oferecer uma experiência moderna, intuitiva e responsiva para estudantes e usuários do ambiente acadêmico.

## 📌 Sobre o projeto

O **UniQ Campus** é uma aplicação web desenvolvida com foco em experiência do usuário, organização de informações acadêmicas e navegação simples e eficiente.

O projeto utiliza uma arquitetura moderna de Front-end, com componentes reutilizáveis e uma interface adaptada para diferentes tamanhos de tela.

## 🚀 Como executar o projeto

### Pré-requisitos

Antes de começar, tenha instalado:

* [Node.js](https://nodejs.org/)
* npm

### Instalação

Clone o repositório:

```bash
git clone https://github.com/joaosystemss/uniqocampus.git
```

Entre no diretório:

```bash
cd uniqocampus
```

Instale as dependências:

```bash
npm install
```

### Ambiente de desenvolvimento

Execute:

```bash
npm run dev
```

A aplicação ficará disponível no endereço indicado pelo Vite no terminal.

## 🏗️ Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```
